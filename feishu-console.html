飞书后台要准备什么？（5 步清单，建应用拿 App ID / Secret）
  1. 飞书开放平台 → 创建「企业自建应用」，起个名字（如「木木-达人助理」）
  2. 应用能力 → 添加「机器人」能力
  3. 事件订阅 → 添加事件 im.message.receive_v1（接收消息），接收方式选「使用长连接接收事件」并保存
  4. 权限管理 → 开通 im:message（读消息）+ im:resource（读图片），发布一个版本
  5. 把「凭证与基础信息」页的 App ID 和 App Secret 填进上面表单 → 点创建
