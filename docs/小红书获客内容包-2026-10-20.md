## 5. 发布与节奏

- **频率**：每周 2–3 条，图文为主（10 粉账号图文也能爆，成本低）
- **评论区运营**：不置顶链接，统一回"私信「工作台」"（提高互动权重+防限流）
- **发布时间**：晚 8–10 点（运营人群刷手机高峰）
- **钩子迭代**：每条只换一个变量（标题 or 首图），跑两周看收藏率，**收藏/点赞 >100% 的公式留下**
- **转化路径**：评论区 → 私信 → 拉飞书群 → 群公告发测试号二维码 → 绑定试用

## 6. 禁区清单（说了必翻车）

| ❌ 不许说 | 为什么 |
|---|---|
| 降维打击 / 吊打达秘 | 防编造纪律，不可验证 |
| 保证出单 / 提升 GMV X% | 结果不可承诺 |
| 免费永久 | 商业化路径已定（积分/会员），说死会反噬 |
| 绕过备案 / 体验版 hack | 教唆规避监管，封号风险 |
| 接入了抖音开放平台 API | 我们是浏览器采集，没接，说了会被较真的人锤 |
| 实时数据 / 7×24 监控 | 周频采集，没有实时，说了就是过度承诺 |
| 用未上线功能当卖点（如"合作机会自动推送"） | 工单还在 backlog，上线前不许写 |
