# Backlog · 达人/商品列表 → 右侧情境抽屉详情 (模式 5)

> 老大 2026-09-19 笔记整理 ·
> SoloBrave 侧栏 5 种高级设计映射里的"上下文"一栏 ·
> **本文件是骨架占位, 暂非可执行文档**

## 1. 目标

达人 / 商品库高频浏览时, 详情用右侧情境抽屉承接, 消灭当前"点行 → 弹全屏 modal → 关闭 → 滚回原位"流程里的上下文丢失.

## 2. 触发场景

- 达人库列表点行 → 达人详情 (替代当前全屏 modal)
- 商品库列表点行 → 商品详情 (替代当前全屏 modal)
- 搜索结果点达人 / 商品 → 同上
- 任务流里引用某达人或商品 → 同上 (任务侧栏标注"引用自 #T-123" / 关闭抽屉回到任务原位置)

## 3. 依赖

排在 D2 (`feat/sidebar-drawer-mobile`) 合入 dev + 480 视觉 pass **之后**:

- 抽屉的断点行为直接复用 D2 的侧栏抽屉基建 (transform 240ms / 抽屉外点击关闭 / Esc 关闭),
 不另造一套 — 同一抽屉组件, 详情面板 = 全宽 drawer 在 ≤768, 右侧 360-480px overlay 在 ≥769
- 移动端 (≤768): 全宽 drawer + 遮罩 (跟 D2 侧栏 drawer 同款)
- 平板 (769-1024): 右侧 360px overlay, 列表区 70% / 详情 30% 拼贴
- 桌面 (>1024): 默认关闭 (避免挤压列表), 用户主动触发

## 4. 明确不做 (防回流)

> 老大约束: 以下两项明确不进 backlog, 防止后续被翻出来重启讨论.

- ❌ **模式 4 (命令式 ⌘K 跳转)**: 当前入口 < 10 个, 点侧栏比敲键盘快; 等模块更多 / 上 SaaS 多项目矩阵后再考虑, 暂缓.
