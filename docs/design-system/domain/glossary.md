# SoloBrave 领域术语词典

> 用途：统一产品 / 设计 / 前端 / 后端 / 运营的术语
> 范围：SoloBrave 抖音团长项目（V1）+ 未来多项目矩阵
> 维护者：产品组

---

## 0. 重要：项目定位澄清

| 概念 | 含义 | 备注 |
|---|---|---|
| **SoloBrave** | 产品名 / 公司品牌 | 一个 SaaS 产品的名字 |
| **抖音团长工具** | SoloBrave 当前的单一项目 | 是 SoloBrave 的 V1 项目，**不是**产品本身 |
| **团长** | SoloBrave V1 项目的产品定位 | **不是系统里的实体**——只是这个项目的名字（"我想成为抖音团长"） |
| 未来项目 | SoloBrave 旗下 sister 产品 | 比如"小红书团长工具"（计划中） |

> ⚠️ **新人最容易踩的坑**：把"团长"当成系统里的一种角色或实体。
> **正确答案**：系统里没有"团长"这个实体，只有"达人/AI 员工/真人/商品/知识库/任务"。

| 任务 | `task_id` | 工作项 | |
| 对话 | `conversation_id` | 用户与 AI 的对话 | 中枢入口 |

## 2. 评级系统（产品视觉签名）

| 等级 | UI 标签 | 后端值 | 含义 |
|---|---|---|---|
| A 级 | A | `rating_a` | 头部达人 / 高 ROI |
| B 级 | B | `rating_b` | 优质 / 主推 |
| C 级 | C | `rating_c` | 一般 / 观察 |
| D 级 | D | `rating_d` | 边缘 / 待复评 |

> **视觉契约**：
> - 卡片左色条颜色 = 头像底色 = 评级色
> - 评级色只用于评级场景，不可挪用

## 4. 会员计划

| UI 标签 | 后端值 | AI 员工数 | 关键能力 |
|---|---|---|---|
| Free | `free` | 1 | 基础分析、手动录入 |
| Pro | `pro` | 3 | 批量截图、API 接入、多达 30 达人 |
| Enterprise | `enterprise` | 不限 | 团队协作、自定义 AI 员工、API 全部功能 |

> AI 员工数 = 定价轴。**这是会员制产品的核心商业模型**。

## 5. 数据通道

| UI 标签 | 后端值 | 状态 |
|---|---|---|
| 抖音截图 | `screenshot_douyin` | ✅ V1 唯一通道 |
| 官方 API | `api_official` | ⏳ 规划中（待抖音开放） |
| 手动表单 | `manual_form` | ❌ V1 不做（截图够用） |
| 批量导入 | `batch_import` | ❌ V1 不做 |

> **架构允许扩展**：所有数据通道进系统后走同一个"AI 复核确认"流。
> **V1 只做截图**，API 接入时**不改 UI 主体**。

## 7. AI 识别置信度

| 标签 | 后端值 | 阈值 | 视觉 |
|---|---|---|---|
| 高 | `high` | ≥ 0.85 | 绿点 + 正常显示 |
| 中 | `medium` | 0.6-0.85 | 黄点 + 提示"建议复核" |
| 低 | `low` | < 0.6 | 红点 + 必填复核 |

## 8. UI 角色（界面上的"角色"含义）

| UI 标签 | 含义 | 能看 | 能写 |
|---|---|---|---|
| 管理员 | 团队 leader | 全部 | 全部 |
| 商务 | 达人侧 | 全部 | 达人字段 |
| 运营 | 商品侧 | 全部 | 商品 |
| AI 员工 | 虚拟员工 | 自己创建的 | 自己创建的 |
| 真人 | 团队成员 | 自己创建的 | 自己创建的 |

> **UI 表达规则**：
> - 角色权限不足时，**按钮可见但触发升级/权限提示**，**不**用禁用灰显
> - 这样保留视觉一致性，又教育用户"我可以升级到能做这件事"

---

## 9. 必须避免的 UI 文案

| ❌ 禁用 | ✅ 改用 | 原因 |
|---|---|---|
| 暂无XX | 你的XX矩阵还是空的 | 数据库式语言 |
| 未填写 | 还未设置 | 用户视角 |
| 系统繁忙 | AI 正在思考中 | 不要让用户以为系统坏了 |
| OpenClaw 已连接 | 服务正常 / ✓ 一切就绪 | **内部 jargon 不外露** |
| 延迟 64ms | (删除) | 外部用户不关心 |
| 失败 | AI 暂时没看懂，请再试一次 | 错误也是品牌时刻 |
| 群组 / 团队（混用） | AI 员工 / 真人 / 虚拟团队 | 三者职责清晰 |

## 10. 业务流程术语

| 概念 | 含义 | 备注 |
|---|---|---|
| 招商 | 招募商家 | 团长项目特有 |
| 选品 | 挑选商品 | 团长项目特有 |
| 分发 | 团长把商品推给达人 | |
| 带货 | 达人通过直播/视频销售 | |
| 履约 | 订单履行 / 物流 | |
| 结算 | 佣金结算 | 团长项目特有 |
| 降佣 | 平台降低佣金比例 | 你的"降佣率"页对应 |

> 这 7 个术语覆盖了抖音团长项目的完整业务流。新前端/设计同事来了先看这一节。
