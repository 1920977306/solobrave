# 商品挂载裁决手册（2026-11-12 定稿）

> 用途：给 products 记录挂 `platform_product_id` 时的证据标准与判例。
> 照此手册走，常规挂载不必逐单回裁。判例细节见交接单 §103。

## 一、证据体系（按权重排序）

| # | 证据 | 权重 | 说明 |
|---|---|---|---|
| 1 | **关键名 token verbatim** | 最强 | 名字的规则：**可简写丢词，不可能凭空长词**。截图名里有的词，正主必有；候选多出系列词（如「青岚」「古韵·秋冬丹宁」）= 我们录入时丢了，方向相反，不构成本排除 |
| 2 | **到手价 ±0.01** | 强 | 几毛价差 = 截图旧值漂移（美印兔兔 9 毛放行案）；差 6% 以上（¥10/¥169）须其他证据补强 |
| 3 | **佣金率** | **参考，不作门槛** | 平台活跃波动（同 pid 两次抓 24%/5% 实证）。落库取平台现值并标注「以平台为准」，预期它会变 |
| 4 | **规格词闸** | 硬闸 | 名中寸/张/P数/双数/克重等规格 token 必须与候选一致，不一致直接出局——同品牌不同 SKU 会撞价佣（12寸 vs 10寸案）。代码：`filing_products.spec_conflict()` |
| 5 | n-gram 覆盖率 ≥0.5 | 只出候选 | 分不清同系列不同款（0.79 系列撞案），**不算证据** |

## 二、判例（三条）

1. **美印兔兔**：三项全过的 12寸 SKU 不挂（规格闸拦），挂同名 verbatim 的 10寸——价格会变，规格和名字不会。
2. **古韵**：平台名「古韵·秋冬丹宁」比我们的「古韵.秋季小个」多词——录入丢词，照样挂。
3. **三本针**：名里缺关键 token「三本针」的候选（句式再像、价接近）排除；挂 token verbatim + 价正中的那条。

## 三、验证口径（按挂载来源分，混用必误报）

| 来源 | 验证 | 通过标准 |
|---|---|---|
| **池内**（出单池挂载） | 下轮团长端统计同步后核 pay_gmv | 出值 = 挂对；恒无值重审 |
| **池外**（按名搜品挂载） | 挂载**一周后**走 worker 按 pid 回搜（`/collect-product-id`） | 名/价/店铺仍一致 = 确认；**pay_gmv 恒空是正常，不是挂错，不作重审触发器** |

## 四、纪律

- **前提不符就停下呈报**——摘要驱动裁决是风险源；全量证据推翻摘要时，hold 比执行值钱。
- **错挂比漏挂贵**；自动闸从严（宁可漏挂），人工裁决按上面权重。
- 挂前整库备份到**仓库外**（`~/.solobrave-backups/`）；`platform_stat_date` = 挂载日；`created_by` 不留空。
