## 批注① hero 标题动态化（方案 A，老大拍板）

- **背景**：老大批注「这里之前就说跟旁边知识库重复了」——侧栏 label「知识库」（模块名）与主区 hero 标题「知识库」（静态）重复。
- **方案 A（本规格）**：hero 标题跟随当前选中分类动态变化 → 侧栏是模块名、hero 是内容名，语义错开不再重复。方案 B（删侧栏副标）弃。
- 现状：`<h1 class="sb2-kb-hero-title">知识库</h1>`（index.html line ~13771，静态写死）。
- 改法：
  1. hero `<h1>` 加 `id="sb2KbHeroTitle"`（DOM 结构不动）。
  2. 标题取值规则：`_sb2KbActiveCat === 'all'` → `'全部知识'`；否则 → 该分类名（从 `_sb2KbCats` 真字段 `name` 取，禁止编造显示名）。
  3. 更新入口：挂进**既有**函数，不造新入口——`sb2KbRenderChips`（chips 选中切换）与侧栏选中回调（`SB2_SIDE_RENDERERS.knowledge` 链路）走到的地方，复用同一个 `sb2KbUpdateHeroTitle()` 小函数（纯 DOM textContent 更新）。
  4. 初始化：`sb2KbInit` 末尾 `_sb2KbInit=true` 前调一次。
- 侧栏 label「知识库」**不动**（模块名保留）。
- 验收（探针 computed/text）：默认态 hero = `全部知识`；点分类 chip → hero = 该分类名；点侧栏分类项 → hero 同步；侧栏 label 仍 `知识库`。

## 批注② 主区列表前端分页（老大拍板：前端分页，页码 123456）

- **背景**：老大批注「这边知识太多了，是不是要弄个，比如什么 123456，就是分页」。
- 现状：只拉 `limit=50` 样本（`sb2KbInit`，line ~40523），列表最多 50 条；总量 123（badge 实测）根本进不来。
- 改法：
  1. **全量拉取（接口契约零改动）**：server 对 `limit` 硬顶 100（solobrave-server.py `_handle_get_kb_entries`：`limit = max(1, min(100, ...))`）。循环 `apiFetch('/api/knowledge/entries?limit=100&offset=N')` 直到返回条数 <100 或已达到 `stats.total`，concat 进 `_sb2KbEntries`。
  2. **分页状态**：新增 `_sb2KbPage`（默认 1）、常量 `_SB2_KB_PAGE_SIZE = 20`。
  3. **渲染切片**：`sb2KbRenderList` 改为只渲染当前页切片（筛选后的数组 `.slice((page-1)*20, page*20)`），函数签名/调用处不改。
  4. **页码条**：列表容器底部渲染 `‹ 1 2 3 … N ›`；总页 ≤7 全显，超出首尾+当前+省略；样式用现有 token（透明底、选中态 `--sb2-s3`、r-sm、12px），不引入新色。DOM class 前缀 `.sb2-kb-pager`。
  5. **重置规则**：chips 筛选 / scope 切换 / 搜索变化 → 回第 1 页再渲染。
  6. 卡片 DOM 结构与 19 轮水平布局（r26.1）**不动**。
- 验收（探针）：全量拉取后 `_sb2KbEntries.length` = stats.total（现 123）；页码条存在且末页 = ceil(筛选后/20)；点第 2 页首卡 = 筛选后第 21 条；chips 筛选后自动回第 1 页。

## 批注③ 详情抽屉 → 居中弹窗 720px（老大拍板：居中弹窗 + 内容展示加大）

- **背景**：老大批注「这个变成弹窗是不是好点，而且内容的展示太少了」——现详情是右侧滑入抽屉 480px，正文可视区窄。
- 现状 CSS（index.html line ~12098）：`.sb2-kb-detail-panel` = `position:fixed; top:48px; right:0; width:480px; height:calc(100vh-48px)` + slide-in 动画；overlay `inset:48px 0 0 0`。
- 改法（**纯 CSS + 动画，DOM 不动**，开/关 JS 逻辑 `classList.add/remove('open')` 不动）：
  1. `.sb2-kb-detail-panel`：改居中——`left:50%; top:50%; transform:translate(-50%,-50%); width:720px; max-width:90vw; height:auto; max-height:80vh;`；删 `top:48px/right:0/border-left`；边框改 `border:1px solid var(--sb2-border); border-radius:var(--sb2-r-lg)`；阴影改居中弹窗款 `0 12px 40px rgba(0,0,0,.12)`。
  2. `.sb2-kb-detail-body`（正文）：`max-height:60vh; overflow-y:auto;`（现 `flex:1` 保留，padding 20 不动）→ 正文展示区显著加大。
  3. `.sb2-kb-detail-overlay`：`inset:0`（全屏遮罩，含顶栏后方）。
  4. 动画：slide-in keyframes 改 fade+scale（`from{opacity:0; transform:translate(-50%,-50%) scale(.96)}` → `to{opacity:1; transform:translate(-50%,-50%) scale(1)}`）；fade-in 保留。
  5. **层叠自检（写进 commit）**：弹窗 z-index 90 > 侧栏 80 > 壳 1，transform 虽建 stacking context 但 z-90 与 z-80 不同级仍赢（18 轮 v3 事故是 fixed 壳与 fixed 侧栏同级层叠，场景不同）；探针必验：弹窗打开时侧栏点击穿透/可见正常、关闭后无残留。
- 验收（探针）：开弹窗 → 面板 rect 水平垂直居中（|centerX-viewport/2|<2px）、width 720、正文 computed `max-height:60vh`；内容超长时正文内部滚动；遮罩全屏；关弹窗 → display:none。
