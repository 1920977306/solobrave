## 1. 背景与现状盘点

prod 商品库现状（探针 + 代码实证）：

- 侧栏：已是 sb2 体系（`SB2_SIDE_RENDERERS.products`，类目组 + 计数，全库聚合 `loadProductCategories`，commit 25 B）。**但类目 onclick 调 `switchProductsCategory` 全仓无定义 → 静默 no-op（点不动，同规律库 24 轮批注④ 病根）**。
- 主区：旧 `module-mid/module-right` 双栏（`#productsMidList` 280px 窄列表 + `#productsRight` 详情栏），唯一未收进 sb2 体系的模块主区。
- 原型：商品库主区是占位（「重设计稿随达人匹配链改造一并出，本原型不展开」solobrave-redesign line 604），无可对照像素稿 → 本规格即设计稿。
- API：`/api/products?limit=&offset=&brand=&status=&sort=&q=`，实测 total=89；单条字段 47 个（关键：name/subtitle/main_image/price/brand/category/stock/status/monthly_sales/monthly_gmv/commission_rates/commission_rate/influencer_count/tags/selling_points/ai_analysis/influencers/videos/createdByName）。
- 现有功能清单（必须全部保留）：搜索 q、品牌筛选、状态筛选（在售/缺货/停售）、6 种排序（默认/价格升降/月销/佣金率/带货达人数）、录入商品（`createNewProduct()` + productModalOverlay）、行点击详情（`selectProductItem` → `renderProductDetail` → #productsRight）、分页、空态（📦 + 录入按钮）、admin 看 createdByName。

### 2.2 数据流（server 零改动）

- 一次性全量拉取：`apiFetch('/api/products?limit=500')`（89 条实测，500 上限够），写 `_sb2PdsProducts` + `_sb2PdsTotal`。
- 类目全库聚合照旧走 `loadProductCategories`（已有，不动），`window.productCategories` 不动。
- 前端过滤：q（name/subtitle/brand 包含）、brand、status、**类目（侧栏 `_sb2PdsCat`，新增）**；排序复用 `sortProductsLocally`（不动该函数，直接调用）。
- 分页：`_sb2PdsPageSize()` 动态页尺寸（第 8 条铁律：每页装满视口不滚动，`floor((main可视高 − hero − filter − pager预留)/(行高+1))`，最小 10 兜底），`_sb2PdsPage` 当前页，resize 200ms 防抖重算不重拉数据。骨架照抄 24 轮 `e1efa7f` 的 kb 分页器实现（`_sb2KbPageSize` 同款公式）。
- 详情弹窗：`.sb2-pds-detail-overlay` + `.sb2-pds-detail-panel`（居中 720px、max-height 80vh、遮罩 inset:0，**纯 CSS 照抄 22 轮 kb 弹窗模式**，z-index 不低于 kb 弹窗），字段渲染迁移 `renderProductDetail` 现有段落（图片/价格/佣金/月销/GMV/转化/受众/达人/视频/selling_points/tags/ai_analysis），数据从 `_sb2PdsProducts` 按 id 取，不再依赖 #productsRight。

### 2.3 接入点（全部比照 sb2PatternsMain  precedent）

1. DOM：`#sb2ProductsMain` 加在 `#sb2PatternsMain` 之后（app-main 内兄弟节点）。
2. CSS：`<style id="sb2-products">` 加在 sb2-tasks style 块附近，全 `var(--sb2-*)` token。
3. init：`function sb2ProductsInit()`，`window.sb2ProductsInit = sb2ProductsInit;`；挂钩位置跟 `sb2PatternsInit` 完全同款（switchModule wrapper / 43606 / 43962 一带所有调用点，逐个对照补）。
4. 互斥：`window.sb2_hideAllModuleMains`（line 46632 选择器清单）加 `.sb2-products-main.active`。
5. switchModule：`moduleMidMap.products` 改 `[]`、`moduleRightMap` 删 products 项（allMids/allRights 隐藏清单保留旧 id 作兜底，旧 DOM 不删）。
6. 侧栏：`SB2_SIDE_RENDERERS.products` 类目 onClick 改调真实函数 `switchProductsCategory('类目名')`（toggle 语义同 `switchPatternsCategory`：再点取消，active 态扫描同款），函数定义在 sb2 products 块内。hero 标题联动：`sb2PdsUpdateHeroTitle()`（类目 > 状态 > 默认「全部商品」），调用点收在 render 函数顶部（同 27 轮规律库修法）。
