## 两问判定（新入口必须全过，否则不做或改成别的）

1. **rail 能不能到？** — 目标模块已在左侧 rail（工作台/AI 办公室/项目组/知识库/规律库/达人库/商品库/任务/设置），且入口是纯模块级跳转（不带任何定位参数）→ **禁做**，rail 就是干这个的。
2. **带不带上上下文？** — 跳转附带定位载荷（任务 ID、员工 ID、通知 ID、筛选状态等），落点模块打开即定位到那件事 → **可以做**，rail 做不到这种深链。

口诀：**「rail 能到 + 空手跳 = 不做；带载荷的深链 = 合理」**
